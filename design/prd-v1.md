# PRD v1 — 最小可行产品

## 产品定义

一个运行在终端的 AI 编程助手 CLI。用户启动后进入交互式对话，输入自然语言，模型返回回复。每次启动为独立会话，会话内保存完整对话历史，退出即结束。

## MVP 功能范围

| # | 功能 | 优先级 | 说明 |
|---|------|--------|------|
| F1 | CLI 启动 | P0 | `npx long-cli` 或 `long-cli` 启动程序，显示欢迎信息，进入 REPL |
| F2 | 用户输入 | P0 | 读取用户在终端键入的一行文本，回车提交 |
| F3 | 模型回复 | P0 | 将用户输入发送给 LLM API，流式输出回复到终端 |
| F4 | 会话管理 | P0 | 每次启动创建新会话，会话内维护对话历史，多轮对话上下文累积 |
| F5 | 退出 | P0 | 用户输入 `exit` / `quit` 或 Ctrl+C 退出程序 |
| F6 | 配置 API Key | P0 | 通过环境变量 `LONG_CLI_API_KEY` 配置 API 密钥，缺失时给出明确提示 |

## 用户故事

1. 作为开发者，我启动 `long-cli`，看到欢迎信息和输入提示，知道程序已就绪
2. 作为开发者，我输入一个问题，看到模型逐字流式输出回复，体验流畅
3. 作为开发者，我连续提问，模型能记住之前对话内容并据此回答
4. 作为开发者，我输入 `exit` 退出程序，下次启动是全新会话
5. 作为开发者，如果未配置 API Key，程序给出清晰提示而非崩溃

## 非目标（MVP 不做）

- 工具调用（文件读写、命令执行等）
- 多 Agent 协作
- 权限模型
- 会话持久化（退出后恢复）
- 多模型切换
- 主题/样式定制
- Markdown 渲染优化
- 并发请求
- 撤销/重做

## 技术约束

- 运行时：Node.js ≥ 18
- 语言：TypeScript
- TUI：React + Ink
- API：Anthropic Messages API（与 Claude Code 对齐）
- 分发：npm 公开发布
- 本地运行，无服务端

## 成功标准

- `npx long-cli` 能启动并进入交互
- 单轮问答正常工作
- 多轮对话上下文正确
- 流式输出无卡顿
- 未配置 Key 时有友好提示
